# استایلفلو باربرشاپ 💈

**نسخه فارسی** | [English](./README.md)

یک اپلیکیشن مدرن و دوزبانه (فارسی/انگلیسی) برای نوبت‌دهی آنلاین آرایشگاه، ساخته‌شده با React ،TypeScript و Vite. طراحی‌شده به عنوان دموی پورتفولیو — کاملا آفلاین‌فرست و بدون نیاز به بک‌اند.

> **🌐 دموی زنده:** https://erpycode.github.io/StyleFlow-Barbershop/

## ✨ امکانات

- **دوزبانه + RTL** — سوییچ یک‌کلیکی بین فارسی و انگلیسی
- **رزرو آنلاین** — فرآیند ۳ مرحله‌ای: انتخاب خدمات ← انتخاب تاریخ و ساعت ← تایید
- **پنل مدیریت** — مدیریت خدمات، نوبت‌ها و تنظیمات سالن
- **خروجی Excel و چاپ** — دانلود نوبت‌های روزانه/کل به صورت `xlsx` یا چاپ گزارش
- **ذخیره‌سازی آفلاین** — همه چیز در LocalStorage مرورگر ذخیره می‌شود؛ بدون نیاز به دیتابیس
- **ظاهر حرفه‌ای** — تم تیره، فونت وزیرمتن، انیمیشن‌های نرم Motion
- **ریسپانسیو** — روی موبایل و دسکتاپ عالی کار می‌کند

## 📦 شروع سریع

```bash
git clone https://github.com/erpycode/StyleFlow-Barbershop.git
cd StyleFlow-Barbershop
npm install
npm run dev
```

بیلد برای پروداکشن:

```bash
npm run build     # خروجی در dist/
npm run preview   # پیش‌نمایش بیلد به صورت محلی
```

## ☁️ دیپلوی

پروژه به صورت خودکار روی **GitHub Pages** دیپلوی می‌شود (فایل `.github/workflows/deploy.yml`) — هر پوش روی `main` سایت را بیلد و منتشر می‌کند.

روش دستی: `npm run build` و آپلود پوشه `dist/` روی هر هاست استاتیک (Netlify ،Vercel ،Cloudflare Pages). چون ۱۰۰٪ استاتیک است، هیچ تنظیم سروری لازم نیست.

## 📁 ساختار پروژه

├── pages/
