# استایلفلو باربرشاپ 💈

**نسخه فارسی** | [English](./README.md)

یک اپلیکیشن مدرن و دوزبانه (فارسی/انگلیسی) برای نوبت‌دهی آنلاین آرایشگاه، ساخته‌شده با React ،TypeScript و Vite. کاملاً آفلاین‌فرست و بدون نیاز به بک‌اند.

> **🌐 دسترسی آنلاین:** https://erpycode.github.io/StyleFlow-Barbershop/

## ✨ امکانات

- **دوزبانه + RTL** — سوییچ یک‌کلیکی بین فارسی و انگلیسی
- **رزرو آنلاین** — فرآیند ۳ مرحله‌ای: انتخاب خدمات ← انتخاب تاریخ و ساعت ← تایید
- **پنل مدیریت** — مدیریت خدمات، نوبت‌ها و تنظیمات سالن
- **خروجی Excel و چاپ** — دانلود نوبت‌های روزانه/کل به صورت `xlsx` یا چاپ گزارش
- **ذخیره‌سازی آفلاین** — همه چیز در LocalStorage مرورگر ذخیره می‌شود؛ بدون نیاز به دیتابیس
- **ظاهر حرفه‌ای** — تم تیره، فونت وزیرمتن، انیمیشن‌های نرم Motion
- **ریسپانسیو** — روی موبایل و دسکتاپ عالی کار می‌کند

## 🧰 تکنولوژی‌ها

| لایه | تکنولوژی |
|------|----------|
| فرانت‌اند | React 18 ،TypeScript ،Vite 5 |

| انیمیشن | Motion |

| ذخیره‌سازی | LocalStorage |
